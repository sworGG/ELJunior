# Анализ API Расписания itport.ugrasu.ru

## Заключение
**itport.ugrasu.ru** использует **Server-Side Rendering (SSR)** на Laravel. Нет открытого REST API для получения расписания.

## Структура URL расписания

### Типы расписаний
```
/timetable/group/{groupId}     - расписание по группе
/timetable/group/{groupId}/{date}  - расписание группы на конкретную дату
/timetable/lecturer/{lecturerId}   - расписание преподавателя
/timetable/auditory/{auditoryId}   - расписание аудитории
```

### Примеры
- Группа ИВТ316 (ID: 8913) текущая неделя:
  ```
  https://itport.ugrasu.ru/timetable/group/8913
  ```

- Группа ИВТ316 на 20 апреля 2026:
  ```
  https://itport.ugrasu.ru/timetable/group/8913/2026-04-20
  ```

## Особенности навигации

### Быстрая навигация
- По дням недели: понедельник, вторник, среда, четверг, пятница, суббота
- По неделям в текущем месяце (напр. 13-19 май, 20-26 май)
- Полный календарь для выбора любой даты

### Параметры URL
Дата передаётся в URL в формате `YYYY-MM-DD` (ISO 8601)

## Использование в мобильном приложении

Поскольку нет открытого API, есть несколько вариантов:

### ✅ Вариант 1: WebView (текущая реализация в MVP)
- **Плюсы**: Полная функциональность, простая реализация
- **Минусы**: Зависит от работы сайта, медленнее

### ⚙️ Вариант 2: Парсинг HTML
- **Плюсы**: Быстрее, можно оптимизировать
- **Минусы**: Хрупкая реализация, может сломаться при изменении HTML

### 🔄 Вариант 3: Запрос к администраторам
- Попросить открытый API для мобильных приложений

## Данные в HTML

Расписание рендерится на сервере в виде таблицы:

```html
<table>
  <tr>
    <td>Время</td>
    <td>Дисциплина</td>
    <td>Поток/Группа</td>
    <td>Кабинет</td>
  </tr>
  <tr>
    <td>09:45-11:05</td>
    <td>Цифровая схемотехника и архитектура ЭВМ</td>
    <td>ИВТ316</td>
    <td>4/405</td>
  </tr>
  ...
</table>
```

## Сессия и аутентификация

- Требуется вход с учётными данными eluniver.ugrasu.ru
- Те же пароли работают на itport.ugrasu.ru
- Cookie сохраняются при входе через браузер
- WebView сохраняет сессию между переходами

## Рекомендация

**Для MVP:** оставить WebView интеграцию как есть.
**Для будущего:** связаться с администраторами ИТ портала и попросить открытый API.
